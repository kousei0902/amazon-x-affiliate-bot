# 商品画像フォルダ

投稿に添付する商品画像を置く場所。

## 使い方

1. Amazonアソシエイト・セントラルにログインした状態で商品ページを開く
2. SiteStripeツールバーの「画像」ボタンから画像を表示 → 右クリックで保存
3. `{商品ID}.jpg`(または `.png` / `.webp`)という名前でこのフォルダに保存する

例: `p019.jpg`(`products.csv` の `id` 列と一致させる)

保存されていれば、次回そのIDの商品が投稿されるときに自動で画像が添付されます。画像が無い場合はテキストのみで投稿されます。

このフォルダの中身(README以外)はAmazonの著作物のためGit管理対象外(`.gitignore`済み)です。ローカルにのみ保存してください。
